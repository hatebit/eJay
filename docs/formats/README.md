# Format reference

Container and companion-file formats used by the eJay products. Start with
[`INDEX.md`](INDEX.md), which groups them by product.

| document | format |
|---|---|
| [`PXD_FORMAT.md`](PXD_FORMAT.md) | `tPxd` (`.pxd`) sample container and DPCM codec |
| [`MIX_FORMAT_DANCE.md`](MIX_FORMAT_DANCE.md) | Dance eJay `.MIX` two-bar blocks, optional metadata and both sample catalogs |
| [`MIX_FORMAT_DANCE2.md`](MIX_FORMAT_DANCE2.md) | Dance eJay 2.0 `.MIX` text catalog, 16 sample tracks, text track and four kit archives |
| [`MIX_FORMAT_HIPHOP.md`](MIX_FORMAT_HIPHOP.md) | Hiphop eJay `.MIX` grid, metadata block and trailer |
| [`MIX_FORMAT_RAVE.md`](MIX_FORMAT_RAVE.md) | Rave eJay `.MIX` grid and `EJAY/PXD` sample index |
| [`MIX_FORMAT_TECHNO.md`](MIX_FORMAT_TECHNO.md) | Techno eJay `.MIX` trailer and event table |
| [`INF_FORMAT.md`](INF_FORMAT.md) | `RAVE20.INF` sample index |
| [`HYPRESET_FORMAT.md`](HYPRESET_FORMAT.md) | Hyper Generator `HYPRESET` records |

The reverse-engineering narrative behind these notes lives under
[`../../work/docs/`](../../work/docs/README.md) and
[`../../work/pxd/`](../../work/pxd/README.md). Editing rules are in
[`../AGENTS.md`](../AGENTS.md).
